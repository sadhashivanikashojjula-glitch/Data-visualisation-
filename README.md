🎬 <b> Movie Data Visualization & Analysis </b> 

📌 <b> <i>  Project Overview </i>  </b>

This project explores a small movie dataset using Python, Pandas, Matplotlib, and Seaborn. The dataset contains information about movie names, genres, ratings, and box-office collections.

The main goal of this project is to understand the dataset through data visualization and exploratory analysis, and to identify patterns and relationships between movie ratings, genres, and collections.

📊 <b> <i> Dataset </i> </b> 

The dataset contains the following features:

Column| Description
"Movie_ID"| Unique identifier for each movie
"Movie_Name"| Name of the movie
"Genre"| Genre/category of the movie
"Rating"| Movie rating
"Collection_Cr"| Box-office collection in ₹ Crores

🔍 <b> <i> Analysis & Visualization </b> </i>

The project explores the dataset using different visualizations, such as:

- 📊 Movie-wise box-office collection comparison
- ⭐ Movie rating comparison
- 🎭 Distribution of movies across genres
- 📈 Relationship between movie ratings and collections
- 🔎 Genre-based analysis
- 📉 Comparative visualizations to identify patterns in the data
